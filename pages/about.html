THE PROJECT

Finding a movie should be easier.

With thousands of movies available, choosing what to watch can be difficult. CineMatix makes discovery easier by using movie content to identify films that are similar to the title or description you provide.

Instead of relying only on a list of popular titles, you can explore recommendations based on what you're interested in watching.

THE TECHNOLOGY

Machine learning meets web development.

CineMatix connects a trained content-based recommendation pipeline to a FastAPI backend and a separate, responsive frontend.

The project brings together data preparation, text vectorization, recommendation logic, API development, and a user interface in one end-to-end application.
